# Support

The Vega Strike: Black Paralysis team has the following support policies:

- Please file an issue in our GitHub Issues as this is the fastest way to get attention from the development team.
- We do try to monitor the following:
   - Gitter.im/Matrix Vega Strike Community (https://gitter.im/vegastrike/community)
   - The Vega Strike Forums (https://forums.vega-strike.org/)
   - Vega Strike IRC Channel
   - Various Vega Strike Emails and Social Media accounts

However we cannot be everywhere. We do ask that you participate in GitHub where the team is centralized.

## Bug Reports

Bug reports are accepted via the following means:

- GitHub Issues on the appropriate project (preferred: https://github.com/vegastrike/vsu-black-paralysis/issues)
- Vega Strike Gitter.im/Matrix Discussion forums
- Vega Strike Forums

The fastest way is to file an issue on GitHub.

## Code Changes

The team primarily accepts contributions through GitHub Pull Requests.

That said, we are aware that some members of the community do not like GitHub and would rather we have an entirely open source platform.
Unfortunately as a project we do not have the funds to be able to operate that way as the fully open source platforms require per user subscription fees.
We do, however, want to hear from you. Please coordinate with us via the Vega Strike Forums to get your patches accepted through an alternate means.

## Supported Engine Versions

Vega Strike: Black Paralysis is maintained against the modern Vega Strike Engine (Assets API Version 3):

| Asset Release | Target Engine Version | Asset API Version | Status |
| :------------ | :-------------------- | :---------------- | :----- |
| 0.1.0+        | Vega Strike 0.11.0+   | 3                 | Active Development |

## Platform Support

Black Paralysis assets are cross-platform and run on all platforms supported by the Vega Strike Engine:
- **Linux** (Debian, Ubuntu, Fedora, openSUSE, Arch, etc.)
- **macOS** (11.0+)
- **Microsoft Windows** (10, 11)
